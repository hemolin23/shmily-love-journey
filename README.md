# 还没有地址的家

一所从一年多聊天记录与图文回忆中梳理出来的 3D 恋爱故事屋。它不再把十二个日期做成照片墙，而是把关系真正发生变化的六个时刻，放进同一栋可以一眼看见全貌的剖面屋。

第二幕是一条可滚动的电影时间轴：鼠标滚轮或触控滑动推动故事前进，进入画面中心的成片会自动放大、静音播放，离开中心后自动暂停。目前保留七条已经完成的影片，其余时间节点以静态记忆卡收束。

## 六个房间

1. 初见玄关：陌生 → 允许靠近
2. 日常厨房：约会 → 生活预演
3. 雨夜站台：浪漫 → 共同承受现实
4. 双城书房：等待见面 → 共同时间
5. Nature 房：二人世界 → 有劳动的共同体
6. 留灯房：证明正确 → 在不确定里陪伴

每个房间都有三件来自真实材料的代表物，一条“共同时间”的灯线穿过整栋房子。全部点亮后，故事收束到一句话：**家还没有地址。今天，有人在等你到家。**

空间文案在 [`src/data/house-story.ts`](src/data/house-story.ts)，完整叙事底稿与逐场剧本在 [`story/`](story/) 中。

## 本地启动

```bash
npm install
npm run dev
```

打开终端显示的本地地址。

```bash
npm run check
npm test
```

当前 TypeScript 检查、离线构建、网页构建与自动化测试均通过（`32/32`）。

## 素材状态

本版不直接陈列聊天截图或把原始记录上传到任何服务。图文材料只用于提炼场景、关系变化和代表物；空间中的郁金香、耳机、火锅、雨伞、双桌灯、猫碗与打结的线，都承担明确的剧情功能。

## 隐私

- 纯本地静态项目，无账号、分析 SDK、业务后端或上传接口。
- 探索进度仅存在浏览器 `localStorage`。
- 源码与公开素材已扫描，不含本机绝对路径、微信 ID 或联系方式。
