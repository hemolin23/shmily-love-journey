# 第八步：剧本医生与空间转换决定

## 诊断结论

完整剧本共十场，约十分钟。故事已经从“十二次见面纪念册”转化为一条可行动的关系主线：两个人试图把异地爱情变成共同生活，必须学习翻译彼此表达爱的方式。

## 已完成的修正

### 1. 旅行节点过多

原问题：十二次见面平均展开会失去戏剧重心。

修正：只保留上海初见、手术分别、双城日常、第一次见 Nature、沟通失效与修复为完整场景；其余城市成为有因果作用的蒙太奇，不再各自占一章。

### 2. “家”容易变成抽象主题

原问题：如果角色不断说“我们像家”，会产生解释性台词。

修正：家只通过动作出现——共用耳机、给对方留饭、报平安、认识通勤路线、铲猫砂、设置提醒、等对方到家。

### 3. 冲突容易被写成谁对谁错

原问题：真实聊天中的长段表达如果直接复制，会伤害隐私，也会让角色失衡。

修正：把冲突压缩为一个可以被拍到的差异：计划表越写越满，另一端的话越说不完。两个人都有合理动机，问题在于语言没有抵达。

### 4. 高潮缺少外部动作

原问题：只让角色“想明白”无法被摄影机拍摄。

修正：shmily 翻过计划表，Odette 停止收拾行李；两个人共同完成第二天对 Nature 的照顾提醒。高潮是一项小而可兑现的合作。

### 5. 结局过度圆满的风险

原问题：虚构同居、婚礼或共同房屋会背离真实状态。

修正：仍然保留两个城市。充电线被理顺但留下小结，表示关系得到新的处理方式，而不是所有问题消失。

## 节奏诊断

- 第1—3场轻快且信息密集，快速建立好感。
- 第4场外部事件不多但情感加重，是第一次减速。
- 第5—6场用重复和路线推进关系，避免持续抒情。
- 第7场短暂回暖，为第8场的下坠提供对比。
- 第8场是情节与情感双高点，不超过全片15%。
- 第9场采用“情节松、情感重”，让等待成为高潮动作。
- 第10场迅速收束，展示新常态，不解释主题。

## 对话诊断

- 删除了人物替观众解释主题的台词。
- 保留短句、重复、话题中断和动作空白。
- 关键句均可由行为支撑：“我还在”“不是不说”“我到家了”。
- 未使用真实隐私长文、身份信息或亲密性内容。

## 最终空间转换约束

1. 空间必须首先让人看见完整关系弧线，而不是十二张图片。
2. 使用六个房间，分别承载六次价值变化；所有房间在总览中同时可见。
3. 每个房间只设置2—4件主物件，其他细节退为环境痕迹。
4. 同一件物品必须有前后回扣，不能只出现一次。
5. 一条可见的“共同时间光线”按时间顺序穿过六个房间，最终连接两盏台灯。
6. 用户可按时间游览，也可直接点击任意房间；故事不再以解锁十二张卡片为主要机制。
7. 最终房间不展示婚礼或共同房产，而展示仍处两地却能够共同生活的新常态。

## 六个空间叙事单元

| 房间 | 关系变化 | 核心物件 |
|---|---|---|
| 01 初见玄关 | 陌生 → 允许靠近 | 白郁金香、单只耳机、行李箱 |
| 02 日常厨房 | 约会 → 生活预演 | 火锅、两双筷子、芒果/桃子/西瓜、手柄 |
| 03 雨夜站台 | 浪漫 → 共同承受现实 | 雨伞、手术腕带、行李箱、车票 |
| 04 双城书房 | 等待见面 → 共同时间 | 两张书桌、两盏台灯、手机、地铁卡 |
| 05 Nature房 | 二人世界 → 有劳动的共同体 | 猫碗、猫砂铲、粮袋、歪掉的手机架 |
| 06 留灯房 | 证明正确 → 在不确定里陪伴 | 计划表、打结充电线、闹钟、两盏灯 |

## 设计签名

六个房间像一座打开正面的玩具屋同时呈现。穿墙的光线不是装饰：它从初见耳机开始，经过锅的蒸汽、雨、地铁路线和猫碗，最后成为两盏台灯之间持续亮着的连接。观众每走完一个房间，光线便多亮一段。
